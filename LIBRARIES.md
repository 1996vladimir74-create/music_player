# Arduino IDE libraries

Install these libraries before compiling:

- MFRC522 — RFID RC522 reader library
- DFRobotDFPlayerMini — DFPlayer Mini control
- Adafruit NeoPixel — WS2812B ring control
- SoftwareSerial — supplied by the ESP8266 Arduino core

Board:

- NodeMCU 1.0 (ESP-12E Module) / compatible LoLin NodeMCU V3 ESP8266

The sketch uses only the previously approved hardware. No IRF520N, no Hall sensor, no extra SD module, and no external amplifier are required.
